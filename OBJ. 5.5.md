### Testing a Network

Networks can be tested using a [[#^d548bf|cable tester]].

An additional tool, the [[#^ee8800|fox and hound (toner probe)]], identifies which cable you're working with.

### Glossary

Cable Tester: A tool used to test network cables. ^d548bf

Fox and Hound (Toner Probe): A tool with two parts. Plug one end into a network jack, then touch the probe to a cable. It alerts you if that cable is the same one plugged into the jack, which identifies which cable you're working with. ^ee8800
