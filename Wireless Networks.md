### Wireless Network Types

Wireless networks are set up in one of four ways:
* [[#^4e8a1c|Infrastructure mode]]
* [[#^b6f03d|Ad hoc mode (IBSS)]]
* [[#^94baa1|Point-to-point]]
* [[#^1d9c7e|Wireless mesh]]

Infrastructure mode is the most common type of wireless network. Ad hoc mode is decentralized and does not require a router or access point.

Infrastructure networks use three identifiers:
* [[#^f4ad3e|Basic Service Set Identifier (BSSID)]]: set to the WAP's MAC address by default
* [[#^ae2efc|Service Set Identifier (SSID)]]: the network name users search for to connect
* [[#^d22e76|Extended Service Set (ESS)]]: multiple WAPs sharing one SSID, called the ESSID

A wireless mesh can combine different radio types into one network, like:
* Bluetooth
* Wi-Fi
* Microwave
* Satellite
* Cellular

Combining two, three, or four of these makes a wireless mesh very redundant, which is why it's most commonly used in disaster relief. Ex. a base camp has Wi-Fi, connects to another base camp over a microwave link, and that base camp connects back to the home country over satellite.

### Access Points

There are two types of access points:
* [[#^9bec5a|Autonomous access point]]: standalone
* [[#^cf9c34|Lightweight access point]]: managed by a centralized controller

### Wireless Antennas

Antennas are designed to send and receive radio signals. The four types are:
* [[#^a76208|Omnidirectional]]: all directions equally
* [[#^179d9b|Unidirectional]]: one direction
* [[#^b4b08e|Yagi]]: one direction, high gain, narrow beam
* [[#^537354|Parabolic]]: a curved dish

### Glossary

Infrastructure Mode: The most common type of wireless network, which uses a wireless access point (WAP) as a centralized point. More organized: devices connect to the network through the WAP. ^4e8a1c

Ad Hoc Mode (Independent Basic Service Set, IBSS): A decentralized wireless network where devices connect directly to each other in peer-to-peer connections, without a central point. Does not require a router or access point, and does not typically provide internet access. ^b6f03d

Point-to-point: Connects two distant, fixed locations over long distances using high-gain antennas. Static and highly efficient, with dedicated bandwidth between the two points. ^94baa1

Wireless Mesh Topology: An interconnection of different types of nodes, devices, and radios. Versatile, resilient, and self-healing, since each node can connect to multiple other nodes. Large-scale. ^1d9c7e

Basic Service Set Identifier (BSSID): A unique identifier for each WAP. Set to the WAP's MAC address by default. ^f4ad3e

Service Set Identifier (SSID): The name of the network, which users search for to connect to it. ^ae2efc

Extended Service Set (ESS): Creates a larger network of multiple WAPs that share the same SSID, allowing seamless connectivity across a large building. In an ESS, the SSID is known as the ESSID. ^d22e76

Autonomous Access Point: A standalone access point that contains all the intelligence to handle wireless networking independently. Useful in small setups, and used by most home users. ^9bec5a

Lightweight Access Point: One of multiple access points that connect back to, and are managed by, a centralized controller. ^cf9c34

Omnidirectional Antenna: Transmits and receives wireless signals equally in all directions. Usually the default type, found in WAPs, mobile hotspots, and embedded devices. ^a76208

Unidirectional Antenna: Focuses on a single direction to provide a more concentrated signal, with long and narrow coverage. Used to reach a remote location from a central area, and frequently used in wireless point-to-point connections. ^179d9b

Yagi Antenna: A directional antenna that provides high signal gain with a narrow beamwidth. Best for capturing or sending signals over long distances to or from a specific, fixed location. Very similar to a unidirectional antenna. ^b4b08e

Parabolic Antenna: A special type of unidirectional antenna that gives the signal a different curvature. Often used with microwave and satellite TV signals. Think of a curved dish. ^537354
