The Presentation Layer is responsible for [[#^8e142b|formatting]] the data being exchanged and securing it with proper [[#^9f253c|encryption]].

Layer 6 includes:
* Scripting languages
* Standard text (like ASCII or Unicode)
* Picture formats (GIFs, JPGs, PNGs)
* Movie file formats
* Encryption algorithms like TLS and SSL

### Glossary

Data Formatting: Data is formatted by the computer to be compatible between different types of devices. Ex. American Standard Code for Information Interchange (ASCII), GIF, JPG, PNG. Provides proper data structures and ensures data is readable by the recipient. ^8e142b

Encryption: Used to scramble data in transit to keep it secure from prying eyes and provide data confidentiality. Ex. The TLS protocol, which creates an encrypted tunnel. ^9f253c
