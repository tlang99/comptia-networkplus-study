The Application Layer is the topmost layer. It provides application-level services where users communicate with the computer, and handles file transfer and network transfer. Not to be confused with apps like Outlook, Google Chrome, etc.

Layer 7 provides [[#^a0364d|Application Services]] and [[#^b1475e|Service Advertisement]].

Layer 7 protocols include:
* Email protocols: POP3, IMAP, SMTP
* Web browsing protocols: HTTP, HTTPS
* DNS
* FTP, FTPS, SFTP
* Telnet, SSH, SNMP

### Glossary

Application Services: Unite communicating components from more than one network application. Includes protocols like POP3, IMAP, and SMTP. ^a0364d

Service Advertisement: Sending out an announcement to other devices on the network to state the services a device offers. ^b1475e
